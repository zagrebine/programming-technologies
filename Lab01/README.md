## Требования

В ходе лабораторной работы необходимо:

1. Создать локальный репозиторий.
2. Сделать первый коммит.
3. Добавить удаленный репозиторий.
4. Загрузить локальные изменения в удаленный репозиторий.

## Ход работы

### 1. Создание локальной директории проекта

Сначала была создана локальная директория, которая в дальнейшем использовалась в качестве проекта.

Для работы использовалась командная строка macOS.

### 2. Инициализация Git-репозитория

В созданной директории был инициализирован Git-репозиторий с помощью команды:

```bash
git init
```

После этого был проверен текущий статус репозитория:

```bash
git status
```

Далее был создан файл `README.md`:

```bash
touch README.md
```

После создания файла повторно была выполнена команда:

```bash
git status
```

В результате Git определил `README.md` как новый файл, который пока не добавлен в индекс.

### 3. Индексация файла и настройка данных пользователя

Для добавления созданного файла в индекс была выполнена команда:

```bash
git add .
```

После этого были настроены имя пользователя и адрес электронной почты, которые Git использует для идентификации автора коммитов:

```bash
git config --global user.name "Егор Загребин"
git config --global user.email "your-email@example.com"
```

Затем изменения были зафиксированы в локальном репозитории с помощью первого коммита:

```bash
git commit -m "Initial commit"
```

Таким образом, первый набор изменений был сохранен в истории локального репозитория.

### 4. Создание удаленного репозитория

Следующим этапом был создан удаленный репозиторий на GitHub.

При создании были указаны:

* название репозитория;
* описание;
* базовые настройки репозитория.

После создания репозитория GitHub предоставил адрес удаленного репозитория.

### 5. Добавление удаленного репозитория

Созданный удаленный репозиторий был связан с локальным проектом с помощью команды:

```bash
git remote add origin <URL-репозитория>
```

Для проверки добавленного удаленного репозитория была выполнена команда:

```bash
git remote -v
```

После этого локальные изменения были отправлены в удаленный репозиторий:

```bash
git push -u origin main
```

В результате локальный репозиторий был связан с репозиторием на GitHub, а созданный ранее коммит был загружен на сервер.

### 6. Проверка истории изменений

Для просмотра истории выполненных коммитов была использована команда:

```bash
git log
```

Команда позволила убедиться, что первый коммит присутствует в истории репозитория.

Также была повторно получена информация о подключенном удаленном репозитории:

```bash
git remote -v
```

В результате была подтверждена связь локального репозитория с удаленным репозиторием на GitHub.
